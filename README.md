A high-performance, visually stunning personal portfolio built with a focus on cutting-edge UI/UX and smooth user interactions. This project showcases a "best-in-class" design philosophy, featuring immersive 3D elements, sophisticated animations, and a seamless responsive experience.

---

## ✨ Key Features

- **🎨 Award-Winning Design**: Premium aesthetic with deep gradients, glassmorphism, and high-contrast typography.
- **🌌 Immersive 3D Hero**: Interactive 3D scene powered by **Three.js** and **React Three Fiber**.
- **🌗 Smart Theme Engine**: Seamless transition between dark and light modes with optimized color palettes.
- **⚡ Performance First**: Lightning-fast load times using **Vite** and optimized asset management.
- **🛠️ Tech Arsenal**:
  - **Frontend**: React 19, TypeScript, Tailwind CSS.
  - **Animation**: Framer Motion (v12), GSAP.
  - **3D**: Three.js, React Three Fiber, Drei.
  - **State/Routing**: Wouter, React Hook Form, Zod.
- **📱 Ultra Responsive**: Fluid layout that adapts perfectly from ultra-wide monitors to the smallest mobile screens.
- **🎯 Micro-Interactions**: Magnetic buttons, custom cursor, scroll reveals, and perspective-parallax cards.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- pnpm / npm / yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abhisekpanigrahy/Personal-Portfolio.git
   cd Personal-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Run development server:**
   ```bash
   pnpm dev
   # or
   npm run dev
   ```

4. **Build for production:**
   ```bash
   pnpm build
   # or
   npm run build
   ```
